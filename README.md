# 암기장

엑셀 파일로 만드는 Anki 방식의 간격 반복 암기장입니다. 설치 없이 아이폰 홈 화면에 추가해서 앱처럼 씁니다.

- **대분류 › 소분류 › 암기장** 3단계로 정리합니다. 학습은 암기장, 소분류, 대분류, 전체 단위로 시작할 수 있습니다.
- **엑셀/CSV 가져오기**: 앞면과 뒷면으로 쓸 컬럼을 각각 여러 개 고를 수 있고, 앞뒤를 바꾼 카드도 함께 만들 수 있습니다.
- 같은 암기장에 다시 가져오면 앞면이 같은 카드는 학습 기록을 유지한 채 내용만 갱신하고, 새 행만 추가합니다.
- **복습 일정**: 다시 / 어려움 / 보통 / 쉬움 평가에 따라 Anki(SM-2)와 같은 방식으로 다음 복습일을 정합니다. 하루 새 카드 수는 암기장별로 설정합니다.
- **스와이프 평가**: 정답을 연 뒤 카드를 ← 다시, → 보통, ↑ 쉬움, ↓ 어려움으로 밀어서 평가합니다. 🔊 버튼으로 카드를 읽어 줍니다.
- **시험일 모드**: 암기장에 시험 날짜를 정하면 시험 전까지 모든 카드를 한 번 이상 보도록 하루 새 카드 수를 자동으로 정하고, 복습 예정일이 시험일을 넘지 않게 당깁니다.
- **약점 카드**: 여러 번 틀렸거나 재학습 중인 카드를 모아 집중 연습합니다(복습 일정은 바뀌지 않음).
- **객관식 퀴즈**: 같은 암기장의 다른 카드 답을 섞은 4지선다 퀴즈입니다. 앞면→뒷면 / 뒷면→앞면을 바꿀 수 있고, 틀린 문제만 다시 풀 수 있습니다(복습 일정은 바뀌지 않음).
- **학습 통계**: 날짜별 학습량 잔디, 연속 일수, 30일 정답률, 앞으로 7일간 복습 예보, 카드 상태 분포를 봅니다.
- **백업 알림 · 암기장 내보내기**: 백업한 지 7일이 지나면 홈에서 알려 줍니다. 암기장 하나만 엑셀(.xlsx)이나 백업 파일(.json, 학습 기록·사진 포함)로 내보내고 다시 가져올 수 있습니다.
- **주관식 입력**: 암기장 설정에서 켜면 정답을 직접 입력해 확인합니다. 틀린 글자와 빠진 글자를 색으로 보여 줍니다.
- **헷갈림 노트**: 퀴즈에서 틀린 보기가 어느 카드의 답이었는지 기록해, 헷갈린 두 카드를 나란히 비교합니다. 짝끼리만 섞은 **짝 퀴즈**, Claude에게 **차이 묻기**를 지원합니다.
- **사진 카드**: 카드 편집에서 앞면·뒷면에 사진을 붙입니다(긴 변 1400px JPEG로 줄여 저장, 백업에 포함).
- **집중 타이머**: 15/25/50분 집중 + 휴식. 끝나면 학습한 카드 수와 정답률을 요약합니다.
- **전체 검색**: 모든 암기장의 앞면·뒷면·메모를 찾습니다. 한글은 초성(ㄱㅎㅅ)만으로도 찾습니다.
- **Claude에게 묻기**: 학습 화면의 💬 버튼을 누르면 현재 카드 내용을 담은 질문으로 claude.ai가 열립니다. 사용 중인 Claude 계정으로 대화하므로 추가 비용이 없습니다. PC에서는 화면 오른쪽에 별도 창으로 열리고 이후 질문도 같은 창을 씁니다. 질문 내용은 클립보드에도 복사됩니다. 받은 답변은 ⋯ → **메모 추가 / 수정**으로 카드에 붙여 넣을 수 있습니다.
- 데이터는 이 기기의 브라우저 저장소(IndexedDB)에만 저장되고 서버로 전송되지 않습니다. 백업 내보내기로 JSON 파일을 저장할 수 있고, 백업 복원으로 되살릴 수 있습니다.
- 한 번 열어 두면 오프라인에서도 동작합니다.

## 엑셀 형식

첫 행에 컬럼 이름이 있고 한 행이 카드 한 장이 되는 표면 됩니다.

| 단어 | 뜻 | 예문 |
|---|---|---|
| apple | 사과 | I ate an apple. |

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다(무료 계정은 Public).
2. 이 폴더의 파일을 모두 올립니다.
3. **Settings → Pages**에서 Source를 `Deploy from a branch`로, Branch를 `main` / `(root)`로 지정하고 저장합니다.
4. 아이폰 Safari로 `https://<아이디>.github.io/<저장소>/`를 열고 **공유 → 홈 화면에 추가**를 누릅니다.

코드를 수정해 다시 올리면 앱을 한 번 열었다 닫은 뒤 다음 실행부터 반영됩니다.

## 주의

- 홈 화면 앱을 삭제하면 데이터도 지워집니다. 주기적으로 **백업 내보내기**를 해 두세요.
- Safari와 홈 화면 앱은 저장소를 따로 씁니다. 반드시 홈 화면에 추가한 앱 안에서 가져오기를 하세요.
